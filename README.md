Sample Spring Boot Website with Spring Security and PostgreSQL</br>
Features:</br>
1.Create and Edit Users with Roles(only profiles with Admin role can create edit and delete data)</br>
2.Create/Edit/Delete Exams</br>
3.Create/Edit/Delete Student Profiles</br>
4.Create/Edit/Delete Courses</br>
5.Create/Edit/Delete Home Page Texts</br>
6.Create/Edit/Delete per Credit Cost
